# AndroidMegaProxy source archive

Original Android artwork retained for reference. `megaproxy-launcher-master.png` and
`featureGraphic.png` were already archived here; `social-preview.png` and
`legacy-notification.svg` preserve the remaining retired Android originals.

Current Android branding is generated from the SVG files in `../../SVG/`:
`icon.svg`, `icon-radius.svg`, `icon-round.svg`, `feature-graphic.svg` and
`icon-taskbar.svg`. Edit those SVG sources instead of archived raster images.
The GitHub download badge remains in AndroidMegaProxy with its own notices.
